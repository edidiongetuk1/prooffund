# Extras

Bonus activities for when you finish early, or want more practice. They use the contracts in this repo, so open a terminal in the `build-day-uyo` folder first.

| Activity | What you'll do | What you need |
|---|---|---|
| [1. Sign the wall](1-sign-the-wall.md) | Put your name on a blockchain | Your phone |
| [2. Send a payment](2-send-a-payment.md) | Send test money to your neighbour | A browser |
| [3. Hello Uyo](3-hello-uyo.md) | Deploy the repo's own hello contract | [Setup](../01-setup/) |
| [4. Prize Pot](4-prize-pot.md) | Lock a prize in a contract, then try to rob it | [Setup](../01-setup/) |
| [5. Web page](5-web-page.md) | Connect a contract to a web page | A browser |
